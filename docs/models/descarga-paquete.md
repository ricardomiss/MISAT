# Descarga Paquete
El proceso de descarga de paquetes en MiSAT permite a los usuarios obtener los paquetes de datos necesarios. Esto devuelve un objeto `byte[]` que contiene los datos para un archivo, este puede ser ZIP pero cambia dependiendo de la respuesta del servicio. Para saber más leer la [documentación oficial del SAT](https://www.sat.gob.mx/portal/public/tramites/factura-electronica).
